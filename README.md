# Bondi Design Project

## Description
This is a modern, responsive landing page called Bondi, built as part of my learning journey in web development. The design focuses on creativity and clean UI.

## Technologies Used

HTML5 & CSS3

Bootstrap 5 (Grid System, Components)

Font Awesome for icons

Google Fonts (Roboto)

## Features

Fully Responsive Design.

Clean and organized code structure.

Modern navigation with sticky-top.

Interactive social media icons in the footer.
